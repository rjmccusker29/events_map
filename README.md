# Events Map

Hosted at [https://events.ryanmccusker.org](https://events.ryanmccusker.org)

This map shows the locations of notable events with all data collected from Wikidata and Wikipedia. Some articles made it through that are not events because I'm a little silly.

Page view-counts are from May 2025, at the time of writing this. I intend to update this data for less biased statistics.

Created by Ryan McCusker. Inspired by Topi Tjukanov's [Notable People](https://tjukanovt.github.io/notable-people) map.
